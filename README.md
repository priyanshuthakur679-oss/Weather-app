# 🌦️ Weather App

A simple and responsive Weather App built using HTML, CSS, and JavaScript. This application allows users to search for any city and view real-time weather information using the OpenWeather API.

## 🚀 Features

* Search weather by city name
* Display current temperature
* Shows weather condition and description
* Humidity information
* Wind speed details
* Responsive design for desktop and mobile devices
* Real-time weather data using OpenWeather API

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* OpenWeather API

## 📂 Project Structure

weather-app/

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/weather-app.git
```

2. Open the project folder:

```bash
cd weather-app
```

3. Open `index.html` in your browser.

## 🔑 API Setup

1. Create a free account on OpenWeather.
2. Generate an API key.
3. Replace the API key in `script.js`:

```javascript
const API_KEY = "YOUR_API_KEY";
```
